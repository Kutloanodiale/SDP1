# Running the Application Locally

Follow these steps to run the application on your local machine.

## 1. Open the Project

Open the project folder in **VS Code**.

## 2. Open the Terminal

In VS Code, open the terminal by selecting:

**Terminal → New Terminal**

Make sure you are in the project directory containing the `package.json` file.

## 3. Install Dependencies

Run the following command:

```bash
npm install
```

This installs all the packages required for the application.

## 4. Start the Application

Run:

```bash
npm run dev
```

This starts the application's development server.

## 5. Open the Application

Once the server has started, the terminal will display a local URL, such as:

```text
http://localhost:3000
```

Open this URL in a web browser to access the application.

## Summary

```text
Open project → Open terminal → npm install → npm run dev → Open localhost:3000
```

The application is now running locally on your computer.
